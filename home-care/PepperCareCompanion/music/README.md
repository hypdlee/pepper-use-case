# Music files (not included)

The songs Pepper plays are commercial recordings, so they are not shipped in this repository. To use the Music activity, put your own copies here under these exact names before you install the package on the robot:

| File | Used for |
|---|---|
| `club-music.mp3` | dance / party track |
| `elvis-fallinginlove.mp3` | song 1 |
| `mamalikedtheroses.mp3` | song 2 |
| `myworldisnotmyhome.mp3` | song 3 |

Any MP3 works as long as the file name matches. Use music you have the rights to play.
