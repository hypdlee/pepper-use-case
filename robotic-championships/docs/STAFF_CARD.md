# Pepper host: staff card

**Open staff mode:** tap the title "IEEE Robot Championships 2026" five times, then type the PIN.

| I want to | Do this |
|---|---|
| See who asked for help | Alerts tab, then tap "On my way" |
| Add or fix a team | Teams tab. Use "Say it as" if Pepper mispronounces the name |
| Add a match | Schedule tab: day, time, game, red and blue corner |
| Finish a match | Schedule tab, "Done" |
| Update scores | Scores tab: choose the team, type the running total |
| Make an announcement | Announce tab: type it, or tap a ready-made one |
| Stop the match calls | Announce tab, "Turn off" |
| Play Pepper's intro now | Announce tab, "Start the intro now" (or Home, "Watch Pepper's intro") |
| Stop the intro | "Skip" on the tablet, or say "stop" |
| Stop the automatic intro | Announce tab, "Stop the automatic intro" ("Allow the automatic intro" brings it back) |
| Stop Pepper talking | Tap "Stop" at the top of the screen, or say "stop" |

**Remember:**
- **Provisional scores.** Scores on Pepper are provisional. The judges announce the official results.
- **Neutral wording.** Pepper treats every team the same way. Please keep announcements neutral too.
- **Not hearing.** If the top of the screen says "Voice not ready", Pepper cannot hear, but the tablet still works. Ask the technical team to stop all behaviours and start the app once.
- **Safety.** Pepper never drives. Do not push or move it while it is running.
- **Closing.** Staff mode closes by itself after 5 minutes without a touch.
